# MindAttic.Legion Project Rules

## Conversation
- A bare "do" / "do it" / "yes" from the user means "continue", "keep going", "proceed". Resume the current task without asking for clarification.

## Codex — how to work in this repo
Canonical documentation lives under `docs/` and follows the MindAttic Codex standard. Read it before changing behavior:
- `docs/BIBLE.md` (L0) — the source of truth: what Legion IS, is NOT, the architecture canon, and the Laws (`{#LEG-LAW-n}`). A fact lives in exactly one place; cite it by its `{#LEG-§n}` / `{#LEG-LAW-n}` / `LEG-US-*` id, never restate it.
- `docs/AMENDMENTS.md` (L1) — append-only change log; an amendment WINS over the bible. Never rewrite one — supersede it.
- `docs/USER_STORIES.md` (L2) — every ✅ story names the test that proves it. Don't mark ✅ without a real, existing test.
- `docs/rfc/` — design notes; graduate accepted ones into L0 + L2, then mark superseded.
- `docs/BIBLE.digest.md` — GENERATED by `tools/codex.ps1 digest`. Never hand-edit. A SessionStart hook (`.claude/hooks/inject-digest.ps1`) injects it as authoritative context.

House rules are INHERITED from `../MindAttic.HouseRules.md` (linked from BIBLE §5) — do not restate or modify them here.

Before finishing doc-affecting work, run:
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/codex.ps1 digest`
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/codex.ps1 doctor`  (must pass)
